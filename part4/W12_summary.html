Complete Analysis Pipeline

Analysis Step Key Functions Checkpoints
1. Data readRDS(), GEOquery N > 30, clear phenotype
2. DESeq2 object DESeqDataSetFromMatrix() Correct design matrix, reference level
3. Filtering rowSums() Low-count genes removed, contaminants removed
4. Normalization DESeq2 internal (RLE) —
5. EDA vst(), plotPCA() No batch effects, no outliers
6. DEG DESeq(), lfcShrink() FDR ≤ 0.05, |LFC| ≥ 1
7. Visualization ggplot2, pheatmap Volcano plot, heatmap
8. Enrichment gseGO(), clusterProfiler NES, FDR (q-value)

Step 1. Data Acquisition

library(TCGAbiolinks)

library(tidyverse)

# Load pre-saved files
countData <- readRDS('examples/data/w6_raw_counts_final.rds')
colData   <- readRDS('examples/data/w6_meta_data_final.rds')

cat("Count matrix:", nrow(countData), "genes x", ncol(countData), "samples\n")
cat("Sample groups:\n"); print(table(colData$tissue_type))
NoteStudy Design Checklist

✅ N > 30 per group: ensures adequate statistical power
✅ Clear phenotype: binary comparison (Tumor vs. Normal, Responder vs. Non-responder)
✅ Potential batch effects: samples from different institutions or time points?
✅ Confounding variables: age, sex, smoking history, treatment history

Step 2. Create DESeq2 Object

library(DESeq2)

# Set factor levels — control group must be the reference!
colData$condition <- factor(
  colData$tissue_type,
  levels = c("Normal", "Tumor")  # Normal is the reference
)

# Build DESeq2 dataset with design matrix
dds <- DESeqDataSetFromMatrix(
  countData = countData,
  colData   = colData,
  design    = ~ patient + condition  # account for paired patient structure
)

Step 3. Pre-filtering: Remove Low-Count Genes

# Method 1: Simple threshold (remove total count < 10)
keep_simple <- rowSums(counts(dds)) >= 10

# Method 2: Group-size-aware filtering (recommended)
# Keep genes with at least 1 count in >= 50% of the smallest group
smallest_group <- min(table(colData$condition))
keep_group     <- rowSums(counts(dds) >= 1) >= (smallest_group * 0.5)

cat("Removed (simple):     ", sum(!keep_simple), "genes\n")
cat("Removed (group-aware):", sum(!keep_group),  "genes\n")

dds_filtered <- dds[keep_group, ]

# Remove confounding gene categories
all_genes  <- rownames(dds_filtered)
mt_genes   <- grep("^MT-",      all_genes, value = TRUE)  # mitochondrial
ribo_genes <- grep("^RPS|^RPL", all_genes, value = TRUE)  # ribosomal
ig_genes   <- grep("^IG[HKL]",  all_genes, value = TRUE)  # immunoglobulin

cat("Contaminating genes to remove:", length(c(mt_genes, ribo_genes, ig_genes)), "\n")

contam       <- c(mt_genes, ribo_genes, ig_genes)
dds_filtered <- dds_filtered[!(all_genes %in% contam), ]

saveRDS(dds_filtered, 'examples/analysis/w6_dds_filtered.rds')

Steps 4 & 5. Normalization and EDA

# Variance Stabilizing Transformation for visualization
vsd <- vst(dds_filtered, blind = FALSE)

# PCA Plot: check for batch effects and outliers
plotPCA(vsd, intgroup = "condition") +
  theme_classic() +
  labs(title = "PCA Plot: Sample Quality Check")
WarningWhat to Look for in the PCA Plot
  • PC1 separates conditions? → Strong biological signal, good to proceed
  • Obvious outliers? → Consider excluding and re-running
  • No clear grouping? → Suspect batch effects; apply limma::removeBatchEffect()

Steps 5 & 6. Differential Expression Analysis

dds <- readRDS('examples/analysis/w6_dds_filtered.rds')

# Run DESeq2 (dispersion estimation → GLM fitting → Wald test)
dds <- DESeq(dds)
saveRDS(dds, 'examples/analysis/w7_dds_DESeq2.rds')

# Extract results (Tumor vs. Normal)
res <- results(dds, contrast = c("condition", "Tumor", "Normal"))
summary(res)

# LFC Shrinkage: stabilize effect size estimates for low-count genes
library(apeglm)
resLFC <- lfcShrink(dds, coef = "condition_Tumor_vs_Normal", type = "apeglm")
saveRDS(resLFC, 'examples/analysis/w9_res_DESeq2_lfcShrink.rds')

Step 7. Visualization

library(ggrepel)
library(pheatmap)

resLFC <- readRDS('examples/analysis/w9_res_DESeq2_lfcShrink.rds')

res_df <- as.data.frame(resLFC) %>%
  rownames_to_column("gene_id")

# ---- Volcano Plot ----
p_thr   <- 0.05
lfc_thr <- 1

vol_data <- res_df %>%
  mutate(diffexpressed = case_when(
    log2FoldChange >  lfc_thr & padj < p_thr ~ "UP",
    log2FoldChange < -lfc_thr & padj < p_thr ~ "DOWN",
    TRUE ~ "NO"
  ))

ggplot(vol_data, aes(x = log2FoldChange, y = -log10(padj), color = diffexpressed)) +
  geom_point(alpha = 0.5, size = 1.5) +
  scale_color_manual(values = c("DOWN" = "blue", "NO" = "grey", "UP" = "red")) +
  geom_vline(xintercept = c(-lfc_thr, lfc_thr), linetype = "dashed") +
  geom_hline(yintercept = -log10(p_thr), linetype = "dashed") +
  geom_text_repel(
    data = head(arrange(vol_data, padj), 10),
    aes(label = gene_id), color = "black"
  ) +
  theme_minimal() +
  labs(title = "Volcano Plot",
       x     = "Log2 Fold Change",
       y     = "-Log10 Adjusted P-value")
# ---- Heatmap of Top 20 DEGs ----
vsd <- readRDS('examples/analysis/w6_dds_vsd.rds')

top_genes <- res_df %>%
  filter(padj < 0.05) %>%
  arrange(desc(abs(log2FoldChange))) %>%
  head(20) %>%
  .$gene_id

mat <- assay(vsd)[top_genes, ]

# Sample annotation sidebar
anno_col <- as.data.frame(colData(dds)[, c("gender", "condition")])

pheatmap(
  mat,
  scale          = "row",   # z-score normalization across samples
  show_rownames  = TRUE,
  show_colnames  = FALSE,
  annotation_col = anno_col,
  cluster_cols   = TRUE,
  main           = "Top 20 DEGs Heatmap"
)

📝 Final Assignment

1. Data Selection

  • Download a Gene Count Matrix + Metadata from a public database (GEO or TCGA)
  • Clearly state the biological context (e.g., “Lung Cancer: Tumor vs. Normal”)

2. Perform the Analysis (apply everything you have learned)

① PCA plot (vst/rlog)  → check for outliers and batch effects
② DESeq2              → identify DEGs with an appropriate design matrix
③ GSEA                → run GO Biological Process (BP) analysis

3. Biological Interpretation (Discussion)

  • Do your top DEGs and enriched pathways agree with established biological knowledge?
  • Compare your findings to the conclusions of the original study

Evaluation focus: Depth and validity of your biological interpretation
