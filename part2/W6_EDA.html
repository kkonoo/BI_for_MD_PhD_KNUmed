1. Explanatory Data Analysis (EDA)

Visualize data before statistical analysis to understand its overall characteristics and quality

  • Quality Control: identify outlier samples
  • Batch Effect Detection: check whether technical noise (experiment date, instrument, etc.) is masking biological signal
  • Heteroscedasticity: variance increases with expression level → a small number of highly expressed genes can dominate the entire analysis

Data Transformation: vst vs. rlog

we need to transform our data (RNA-seq data) for statistic analyses

Caution

vst/rlog transformed values are for visualization only; raw counts must be used for differential analysis!

vst (Variance Stabilizing Transformation)

  • Suitable for n ≥ 30 (large sample sizes)
  • Based on a global trend → fast
  • asinh transformation for highly-expressed genes

rlog (Regularized Log)

  • Suitable for n < 30 (small sample sizes)

  • Per-gene shrinkage (Bayesian estimation) → slow

  • Suppresses noise in low-count genes

    e.g.,

    gene A (low):
    sample 1: 1, sample 2: 5 ➡️ logFC = log2(5/1) = 2.32 … noise ↑

    gene B (high):
    sample 1: 1000, sample 2: 1004 ➡️ logFC = log2(1004/1000) = 0.005 … noise ↓ (stabilized)

2. Visual Exploration (QC Part II)

What to check through visualization:

  • Is there a difference between groups?
  • Are there any outlier samples?
  • Is there a batch effect?

Sample Correlation Heatmap

library(pheatmap)
library(RColorBrewer)

sampleDists <- dist(t(vsd_data))
sampleDistMatrix <- as.matrix(sampleDists)
rownames(sampleDistMatrix) <- paste(vsd$condition, vsd$type, sep = "-")
colnames(sampleDistMatrix) <- NULL

colors <- colorRampPalette(rev(brewer.pal(9, "Blues")))(255)
pheatmap(sampleDistMatrix,
         clustering_distance_rows = sampleDists,
         clustering_distance_cols = sampleDists,
         col = colors)

PCA Plot

# PCA
pca_res <- prcomp(t(vsd_data))
pca_coords <- as.data.frame(pca_res$x[, 1:2])

ggplot(pca_coords, aes(x = PC1, y = PC2)) +
  geom_point(size = 3) +
  ggtitle("PCA Result") +
  theme_bw()

PCA vs. MDS

PCA MDS
Input Raw data matrix (sample × gene) Distance matrix (sample × sample)
Goal Preserve variance Preserve pairwise distances
Method Eigen decomposition Coordinate reconstruction
Benefit Loadings reveal important genes Supports various distance metrics
(Euclidean-PCA, Correlation, Bray-Curtis)
Use General QC, sample clustering Microbiome, non-Euclidean distance

3. Batch Effect

  • Technical noise arising from experiment date, sequencing platform, operator, etc.
  • Inspect alongside batch metadata in the PCA plot
  • Correction strategies:
    • For visualization: use residuals from limma::removeBatchEffect()
    • For statistical testing: include batch in the design matrix (covered next week)
library(limma)

mat <- assay(vsd)
mm <- model.matrix(~condition, colData(vsd))
mat2 <- removeBatchEffect(mat, batch = vsd$patient, design = mm)

# PCA after batch removal
rv <- rowVars(mat2)
select <- order(rv, decreasing = TRUE)[seq_len(min(500, length(rv)))]
pca <- prcomp(t(mat2[select, ]))
percentVar <- round(100 * pca$sdev^2 / sum(pca$sdev^2))

pcaData2 <- data.frame(PC1 = pca$x[, 1], PC2 = pca$x[, 2],
                        condition = colData(vsd)$condition)

ggplot(pcaData2, aes(x = PC1, y = PC2, color = condition)) +
  geom_point(size = 3) +
  xlab(paste0("PC1: ", percentVar[1], "% variance")) +
  ylab(paste0("PC2: ", percentVar[2], "% variance")) +
  ggtitle("PCA - After Patient Effect Removal") +
  theme_bw()
